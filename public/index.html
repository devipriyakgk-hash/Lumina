New to this? Quick meanings

Accessibility
Making a site usable for everyone — including people who use a keyboard or a screen reader.
Alt text
A short description of a picture, so someone who cannot see it still knows what it is.
Screen reader
Software that speaks the page out loud. It can only say what the HTML actually names.
Label
A name for a button or input. Without it, assistive tech cannot say what the control does.
